Straßennetz als Graph

Modellierung

Graph \(G = (V, E)\)

  • Knoten \(V\): Orte (Küche, Filialen) und Verknüpfungspunkte (Autobahnkreuze)
  • Kanten \(E\): direkte Straßenverbindungen
  • Kantengewicht \(c_{vw} \geq 0\): Länge, Fahrzeit oder Kosten
  • ungerichtet, wenn beide Richtungen gleich lang sind; sonst gerichtet (Einbahnstraßen, Auffahrten)

Weg von \(s\) nach \(t\): Folge benachbarter Knoten; Länge = Summe der Kantengewichte

Das SushiFresh-Netz hat 10 Knoten und 16 Kanten (vereinfacht).

Als Netzwerkflussproblem

Ein Kürzeste-Wege-Problem ist ein Transportproblem auf einem Netz: Eine Einheit fließt von \(s\) nach \(t\).

\[\min \sum_{(v,w) \in E} c_{vw} \, x_{vw}\] \[\sum_{w} x_{vw} - \sum_{w} x_{wv} = \begin{cases} 1 & v = s \\ -1 & v = t \\ 0 & \text{sonst} \end{cases}\] \[x_{vw} \geq 0\]

Mit spezialisierten Algorithmen geht es aber deutlich schneller als mit einem LP-Solver.

Dijkstra-Algorithmus

Idee

Idee (Dijkstra 1959): Breite dich vom Startknoten \(s\) wie eine Welle aus. Jeder Knoten \(v\) trägt eine Marke \(d(v)\) (bisher kürzeste bekannte Entfernung) und einen Vorgänger \(p(v)\). In jedem Schritt wird der nächstgelegene noch offene Knoten endgültig („permanent“) markiert.

Zwei Arten von Marken

  • temporär: vorläufiger Wert, kann noch verbessert werden
  • permanent: endgültig kürzeste Entfernung

Warum ist der kleinste temporäre Wert endgültig? Jeder andere Weg müsste über einen Knoten mit größerer Marke laufen und kann wegen \(c_{vw} \geq 0\) nicht kürzer werden.

Kernoperation: Markenkorrektur

Für jeden Nachbarn \(w\) des neu permanenten Knotens \(v\): \[d(w) \leftarrow \min\big(d(w),\; d(v) + c_{vw}\big)\] Verbessert sich \(d(w)\), wird \(p(w) \leftarrow v\) gesetzt.

Voraussetzung: keine negativen Kantengewichte.

Dijkstra-Algorithmus

Algorithmus

Initialisierung: \(d(s) = 0\), \(d(v) = \infty\) für alle \(v \neq s\); alle Marken temporär; \(p(v) = \text{–}\)

Wiederhole, bis alle Knoten permanent sind:

  1. Wähle den temporär markierten Knoten \(v\) mit kleinstem \(d(v)\).
  2. Markiere \(v\) permanent.
  3. Für jeden temporär markierten Nachbarn \(w\) von \(v\):
    • falls \(d(v) + c_{vw} < d(w)\): setze \(d(w) = d(v) + c_{vw}\) und \(p(w) = v\)

Ergebnis: \(d(v)\) = kürzeste Entfernung von \(s\) nach \(v\); der Weg ergibt sich durch Rückverfolgung der Vorgänger \(p(v)\).

Aufwand

  • \(n\) Iterationen, je Iteration Minimumsuche über \(n\) Knoten → \(\mathcal{O}(n^2)\)
  • mit Prioritätswarteschlange (Heap) → \(\mathcal{O}(|E| + n \log n)\)
  • Ein Navigationssystem durchsucht so Millionen Knoten in Millisekunden (mit Beschleunigungen wie A*).

Notation im Fallbeispiel

Marke „\(d\) | \(p\)“, z. B. „15 | MH“ = 15 km, Vorgänger Mönchhof-Dreieck

Dijkstra-Algorithmus

Implementierung in R

# W: Gewichtsmatrix (0 = keine Kante)
dijkstra <- function(W, start) {
  ids  <- rownames(W)
  d    <- setNames(rep(Inf, nrow(W)), ids)
  pred <- setNames(rep(NA, nrow(W)), ids)
  perm <- setNames(rep(FALSE, nrow(W)), ids)
  d[start] <- 0
  while (!all(perm)) {
    # 1. kleinste temporäre Marke
    v <- names(which.min(ifelse(perm, Inf, d)))
    # 2. permanent markieren
    perm[v] <- TRUE
    # 3. Markenkorrektur der Nachbarn
    for (w in ids[W[v, ] > 0 & !perm]) {
      if (d[v] + W[v, w] < d[w]) {
        d[w]    <- d[v] + W[v, w]
        pred[w] <- v
      }
    }
  }
  list(d = d, pred = pred)
}

Eigenschaften der Distanzmatrix

  • symmetrisch (ungerichtetes Netz)
  • erfüllt die Dreiecksungleichung \(d_{ik} \leq d_{ij} + d_{jk}\), denn jede Direktverbindung ist bereits ein kürzester Weg
  • enthält nur noch die relevanten Orte, die Autobahnknoten sind „herausgerechnet“

Kürzeste Wege in der Praxis

Varianten und Erweiterungen

Weitere Algorithmen

  • Bellman-Ford: erlaubt negative Kantengewichte (z. B. Rückfrachten mit Erlös), \(\mathcal{O}(n \cdot |E|)\)
  • Floyd-Warshall: alle Paare auf einmal, \(\mathcal{O}(n^3)\)
  • A*: Dijkstra mit Schätzung der Restentfernung (z. B. Luftlinie) → durchsucht viel weniger Knoten

Was ist „kurz“?

  • Distanz (km): Kraftstoff, Verschleiß
  • Fahrzeit: Personal, Frische der Ware, Lieferfenster
  • Kosten: Maut, Fahrzeugkosten
  • zeitabhängig: Berufsverkehr auf der A3 um 7 Uhr ≠ um 4 Uhr

Je nach Zielgröße ergeben sich unterschiedliche kürzeste Wege.

Kernaussagen

Das Wichtigste in Kürze

  • Straßennetze werden als Graphen modelliert. Transportkosten \(c_{ij}\) ergeben sich aus kürzesten Wegen im Netz, nicht aus der Luftlinie.
  • Der Dijkstra-Algorithmus markiert schrittweise den nächstgelegenen offenen Knoten permanent und korrigiert die Marken seiner Nachbarn. Voraussetzung: nichtnegative Gewichte.
  • Temporäre Marken können sich noch verbessern (SushiFresh: Frankfurt von 33 auf 28 km).
  • Mehrfaches Anwenden liefert eine symmetrische, metrische Distanzmatrix, die Grundlage der Tourenplanung.
